# Pulse Chandelier: Layout Viewer

Interactive 3D viewer of the Pulse Chandelier (Miami) by Rafael Lozano-Hemmer / Antimodular.

It shows the position, ID and cable length of each of the 300 bulbs hanging from the canopy. Data: `pulsechandelier_miami_nov25.csv`. The layout is subject to change.

## How to use

- Drag to rotate, scroll to zoom, right-drag to pan
- Hover a bulb to see its details, click it to select it
- Use the view buttons (3D, Eye level, Front, Side, Plan, Below) to change angle. Plan matches the L&F "view from top" drawing (#A01 bottom-left)
- Find a bulb by ID (e.g. #A01) and step through IDs with ‹ ›
- "Measure between two bulbs" gives the distance between any two points
- Drop or open another CSV to view it (only in your own browser)
